AgentMine

Build an agent the way you'd build a checklist.

AgentMine is a visual tool for assembling a working AI agent out of simple, reusable building blocks — then watching it run, in real time, against realistic scenarios. It's a preview of how we like to make AI legible: something you can watch work, not just trust blindly.

  • Build

    Stack simple blocks

    Snap together steps and equip them with the capabilities they need — no wiring diagrams, no code required.

  • Run

    Watch it think

    Press run and follow a live simulation that lights up each step, with plain-language notes on what happened and why.

  • Practice

    Test it before it matters

    Run the agent through realistic scenarios and see exactly what it got right, what it missed, and where to improve — before it touches real work.

flakelens · open source

Is that LLM failure real, or did you just get unlucky?

Your eval says 8 / 10 passed. That single number can't tell you whether the prompt is genuinely broken or merely nondeterministic — and those need opposite fixes. flakelens runs each case many times and separates them, with a confidence interval so you know how far to trust the split. Free, MIT-licensed, no dependencies.

  • Broken

    Fails every single run

    A real defect in the prompt or the chain. Deterministic, reproducible, and fixable — the report names exactly which check failed.

  • Flaky

    Fails some of the time

    Usually temperature, prompt sensitivity, or retrieval nondeterminism. Reported with a pass rate and a 95% interval instead of a misleading pass/fail.

  • Honest

    Ten green checks isn't proof

    At 10/10 the true pass rate is only ≥ 72%. flakelens says so, and tells you 73 consecutive passes are needed before claiming 95%.

Python developer tools · MIT licensed

See the quality and cost changes behind an LLM result.

Three small tools for teams evaluating prompts, agents, and retrieval. They use the measurements you provide; they do not call a model or intercept your provider traffic.

  • Spend guardrail

    llmbudget

    Set caller-recorded USD, token, and call ceilings. A breach raises immediately so runaway loops can stop. It is a guardrail, not a request proxy or invoice.

  • Retrieval audit

    retrievalcheck

    Score a retriever against labeled queries. Review recall, ranking, missed relevant chunks, and character-based context-waste estimates.

  • Prompt comparison

    tokendiff

    Compare two evaluation runs side by side: token and cost changes plus the individual cases that passed or failed after an edit.

AgentPath · local workflow trace reviewer

One successful tool call does not prove the workflow worked.

Compare an expected agent journey with a captured JSON trace. Check step order, values passed between tools, approval guards, tool errors, and repeated writes. The review runs in your browser and does not invoke a model or connect to a server.

  • Sequence

    Expected steps, in order

    Flag missing steps, an unexpected tool, an error result, or an event outside the declared workflow.

  • Handoff

    Keep the right entity

    Capture an ID or version from one result and require later tool arguments to carry that exact value.

  • Side effects

    Make approval checks visible

    Require a prior captured approval before a write, flag repeated writes, and download a JSON findings report.

CSV Flight Check · data tool

Catch CSV import problems before they become cleanup work.

A small, local-first preflight for CSV and TSV files. It flags structural issues, whitespace, duplicate rows, mixed date styles, and formula-like cells. Choose the reversible fixes you want, preview the result, and export a cleaned copy plus an issue report. The file stays in your browser; nothing is uploaded.

  • Inspect

    See the shape of the file

    Check headers, row widths, blank rows, missing cells, and likely date-style inconsistencies before importing.

  • Review

    Keep decisions visible

    Exact duplicates and whitespace are counted. Ambiguous values are flagged for a person to decide, never guessed.

  • Export

    Take away a checked copy

    Apply only the cleanup rules you select, then download the result and a compact JSON issue report.
