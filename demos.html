No account, no install, no upload. These run entirely in the page you are looking at — your data stays in the tab and is never sent to VitaPilot AI or to a model.

  • AgentPath

    Did the workflow do the right work?

    The problem: every tool call returned 200, and the agent still did the wrong thing. What it does: checks a captured JSON trace against the steps you expected — order, values handed between calls, approval guards, errors, repeated writes. The limit: a pass means the trace matched your checks, not that the real-world effect was correct.

    Review a trace →

  • CSV Flight Check

    Will this file import cleanly?

    The problem: the import fails at row 4,000, or worse, succeeds and quietly corrupts a column. What it does: flags ragged rows, stray whitespace, duplicate rows, mixed date styles and formula-like cells, then applies only the fixes you pick. The limit: ambiguous values are flagged for a person, never guessed.

  • AgentMine · preview

    What will this agent do before it does it?

    The problem: agent behaviour is hard to reason about until it has already run. What it does: assembles an agent from reusable blocks and simulates it step by step against realistic scenarios, in plain language. The limit: this one is an internal preview — there is no public build to click yet.

Install from PyPI

Four narrow tools for LLM reliability and cost.

MIT licensed, zero dependencies, Python 3.10+, tested on 3.10 through 3.13. Each answers one question and refuses to pretend it answers the others. They compose, but none of them needs the rest.

  • flakelens

    Is this failure real, or just flaky?

    The problem: a case fails once and you cannot tell a broken prompt from an unlucky roll. What it does: runs each case N times and splits broken from flaky, with a Wilson interval — 10/10 means ≥72% true pass rate, not 100%. The limit: deterministic checks only.

    pip install flakelens
    Details · Source

  • retrievalcheck

    Did retrieval find the right chunk?

    The problem: the answer was wrong and you cannot tell whether the model failed or retrieval never found the passage. What it does: measures recall@k, MRR, and the share of context you paid for that was irrelevant. The limit: you supply the ground truth.

    pip install retrievalcheck
    Source

  • tokendiff

    Did this prompt change break anything?

    The problem: trimming a prompt saves money and quietly damages a handful of cases. What it does: reports the token and cost delta next to which cases flipped, calling a cheaper-but-damaging change a trade, not a win. The limit: the decision stays yours.

    pip install tokendiff
    Source

  • llmbudget

    What stops a runaway agent loop?

    The problem: a retry loop bills you for every iteration and the dashboard tells you tomorrow. What it does: enforces a hard ceiling on dollars, tokens or calls and raises the moment one is breached. The limit: a guardrail, not an invoice.

    pip install llmbudget
    Source

Where each one fits

Different questions, different points in the life of a change.

  1. 01

    Before you merge

    tokendiff compares the old prompt with the new one and fails the build if tokens climb or cases break. flakelens tells you whether a failure is worth chasing.

  2. 02

    When the answer is wrong

    retrievalcheck settles whether retrieval or generation is at fault, and how much irrelevant context you are paying to send. AgentPath does the same for a multi-step workflow.

  3. 03

    While it runs

    llmbudget caps what a block of code may spend, so a loop that goes wrong stops at your ceiling instead of at your credit limit.
